# Restaurant-Management-System
ABSTRACT
The Restaurant Management System is a software solution developed to streamline order management and enhance customer satisfaction. It features an interactive graphical user interface (GUI) that facilitates dynamic menu management, order processing, and a review system for customer feedback. Key functionalities include adding/removing items to/from the order, generating unique order IDs, saving order details in a database, and collecting customer reviews. This project uses Python, Tkinter for the GUI, pyodbc for database connectivity, and MS Access for persistent data storage. The system emphasizes modularity, scalability, and userfriendly design to ensure an enhanced restaurant experience.
